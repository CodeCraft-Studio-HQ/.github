# CodeCraft Studio

**We build custom web apps, mobile apps and websites for clubs, events and small businesses in Croatia and beyond.**

A small team of three developers: two backend, one frontend. We like software that is simple to use, quick to ship and easy to maintain.

## What we do

- **Custom web apps and dashboards:** admin panels, internal tools, booking and registration systems
- **Mobile apps:** iOS and Android apps with a matching backend
- **Websites:** fast, clear and easy for you to update
- **Maintenance and support:** we stay with the project after launch
